# Archive — Initial Exploratory Prototype

This directory contains the earliest exploratory prototype of the project (`race_data.csv` and `f1_thesis_analysis.ipynb`), built using manually compiled data across 4 circuits from the 2025 F1 season (Bahrain, Monza, Silverstone, and Monaco).

It is preserved strictly for historical reference. All active development, automated data ingestion via the FastF1 API, data cleaning, feature engineering, and statistical modeling now live in `src/`, `data/`, and `notebooks/`.
